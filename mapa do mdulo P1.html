3. Regras de Acesso e Permissões (Roles)

Permanente da Guarda

Operador direto do Turno A (06h-18h) ou Turno B (18h-06h). Preenche o livro utilizando a busca inteligente de efetivo, registra viaturas e ocorrências, gera o PDF, assina via Gov.br e faz o upload.

P1 (Chefe de Secretaria / DP)

Supervisor do setor. Possui acesso de fiscalização, auditoria e acompanhamento de todos os livros diários da unidade gerados pela permanência.

Master

Possui acesso irrestrito, total e administrativo a todas as funções e visualizações de qualquer setor do sistema, incluindo P1 e P4.

4. Arquitetura das Tabelas do Banco de Dados (Supabase / PostgreSQL)

Abaixo os scripts SQL oficiais para criação das tabelas no Supabase:

-- 1. Tabela Principal do Livro da Permanência
create table if not exists livros_permanencia (
  id uuid default gen_random_uuid() primary key,
  data_servico date not null,
  turno varchar(10) not null, -- 'A' ou 'B'
  permanente_nome text not null,
  antecessor_nome text,
  substituto_nome text,
  status varchar(30) default 'abrito', -- 'abrito', 'aguardando_assinatura', 'assinado'
  arquivo_assinado_url text, -- Caminho ou URL do PDF assinado salvo no servidor/Drive
  created_at timestamp with time zone default timezone('utc'::text, now()) not null
);

-- 2. Tabela de Controle de Viaturas do Livro
create table if not exists livro_viaturas (
  id uuid default gen_random_uuid() primary key,
  livro_id uuid references livros_permanencia(id) on delete cascade,
  viatura text not null,
  km_inicial numeric,
  km_final numeric,
  km_abastecimento numeric,
  litros numeric,
  valor numeric,
  saldo numeric,
  status_viatura text default 'disponivel', -- 'disponivel', 'baixada'
  motivo_baixa text,
  local_baixa text,
  motorista text,
  destino text
);

-- 3. Tabela de Ocorrências do Livro
create table if not exists livro_ocorrencias (
  id uuid default gen_random_uuid() primary key,
  livro_id uuid references livros_permanencia(id) on delete cascade,
  horario time not null,
  descricao text not null
);
